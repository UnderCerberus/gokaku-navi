# GOKAKU NAVI — 志望校逆算ダッシュボード

大学受験生向けの学習ダッシュボード。数学・英語・物理の過去問演習、途中式つき計算機、公式シミュレーター、和訳ツールを 1 画面に統合。
**外部 API・CDN・Web フォントを一切使わない完全オフライン動作**（すべてのロジックとデータはこのフォルダ内の JavaScript）。

## 使い方

`index.html` をブラウザ（Chrome / Edge）で開くだけ。学習記録はブラウザの localStorage に保存される。

1. 画面最上部で **学年・現在の偏差値・志望大学の偏差値** を入力
   → 入試本番日を自動予測してカウントダウン、偏差値ギャップから **今週のノルマ** を算出、過去問レベル（基礎 / 中堅 / 難関）を自動切替
2. **過去問モード** に切り替えると勉強タイマーが自動で動く。問題を解いて「採点する」
   → 間違えると、前提となる 1 つ前の範囲の「要復習」カードが ToDo に自動で入る → 「復習を始める」で基礎演習
3. **計算機モード** は学習補助ツール（タイマー停止）
   - 数学: 数値を入れると途中式とステップごとの解説を表示（学年に応じて「やさしく / 標準 / 簡潔」を自動選択）
   - 物理: 公式シミュレーター（図つき）。「この単元のランダム演習を解く」で数値が毎回変わる演習へ
   - 英語: 和訳ツール（左に英文、右に和訳・重要語句・文法ポイント・単語クイズ）

## 自動判定のしくみ（すべて `js/app/` 内）

| 機能 | 場所 | ロジック |
|---|---|---|
| 入試日の予測 | `dashboard.js` `predict()` | 学年 → 受験年度。志望偏差値 50 未満 = 共通テスト（1/13 以降の最初の土曜）、50〜60 = 2/7、60〜65 = 2/13、65 以上 = 2/25（国公立前期） |
| 今週のノルマ | `dashboard.js` `plan()` | 偏差値ギャップ × 1 ポイントあたり必要時間（基礎 40h / 中堅 60h / 難関 90h）÷ 残り週数。教科配分は直近の正答率が低い教科に厚く |
| レベル切替 | `core/ns.js` `JK.cfg.levels` | 志望偏差値 < 50: 基礎 / 50〜60: 中堅 / 60 以上: 難関 |
| 復習連動 | `analysis.js` `decide()` | 誤答した単元の前提単元（`data/units.js` の `prereq`）ごとに「原因の重み × 定着度係数」をスコア化し、1.0 以上で「要復習」カードを生成 |
| 自動採点 | `core/util.js` `JK.check` | 数値（`3/4`, `2√3`, `π/6` 可）・数式（乱数代入で等価判定）・選択・語句・並べ替え |

## 和訳ツールのしくみ（`js/english/`）

外部の翻訳サービスは使わず、内蔵の対訳・辞書・文法規則だけで動く。文ごとに次の順で訳を決め、どの方法で作った訳かをバッジで示す。

| バッジ | 方法 | 精度の目安 |
|---|---|---|
| 完全一致 | 内蔵長文（約 620 文）の対訳と一致した文は、人が書いた訳をそのまま表示。引用符で 2〜3 文に分かれた対訳もまとめて照合する | 高い |
| 類似文 | 語の並びが 8 割以上一致する内蔵文の訳を表示（否定語・数が食い違う文は採らない）。もとの文を「出典」に併記。使うのは構文解析できない文と、違う語がつづりの誤りだけの文に限る。辞書にある語が違う文は「構文パターン」で訳し、似た内蔵文の対訳は語注の欄に参考として出す | 違う語は語注で確認 |
| 構文パターン | 文を構文解析（主語・動詞・目的語、時制・助動詞・受動態、不定詞・動名詞・分詞、関係詞・接触節、比較、仮定法、形式主語、同格、疑問文・命令文、`"…" he said.` のような直接話法、コロンで区切った文など）して日本語の語順に組み立てた訳 | 教科書レベルの文なら自然。訳語は辞書の第 1 義なので、文脈に合わないことがある |
| 辞書直訳（参考） | 解析できなかった文を、句ごとに区切って訳したもの（スラッシュ訳） | 参考程度 |

- `lemma.js` 活用形 → 原形（不規則動詞 約 170 語・規則変化）と辞書引き ／ `ja.js` 日本語の活用 ／ `syntax.js` 構文解析と訳の組み立て ／ `grammar.js` 文法ポイント ／ `translator.js` 全体の入口（翻訳メモリ・語注・熟語検出・単語クイズ）／ `ui.js` 画面
- 内蔵長文以外の英文（エンジンが調整に使っていない新しい文）で測ると（2026-10-09、`tools/en/heldout/` の 7 群 約 280 文。各群は直す前に測った値）、教科書・問題集レベルの 10〜20 語の文はおよそ 8 割前後、お知らせ・メール・会話の文もおよそ 8 割が意味の通る訳になる。20 語を超える長い文は 4〜6 割に誤り（解析できない・意味が違う）が残った。長い文・並列の多い文ほど誤りやすい。機械的な訳は参考にとどめ、語注と文法ポイントで意味を確かめる使い方を想定している。測り直すときは新しい文で `node tools/en/ho.js 文のファイル` を使う（回帰文に入れた文は測定に使わない）。
- 単語クイズは辞書から 4 択を自動生成する（誤答は同じ品詞・近いレベルで語義が重ならない語）。回答は学習記録に反映される。

## データの追加・編集

- 画面から: 過去問モードの「＋ 過去問を自分で追加」（この端末に保存）
- ファイルで: `js/data/` に問題ファイルを置き、`index.html` の `<script>` に 1 行足す。形式は [docs/CONTRACT.md](docs/CONTRACT.md) §4。
  大学名・年度は各問題の `source: { univ, faculty, year, no, kind }` に書く。
- 英語長文を足すと（`JK.registerPassages`、文単位の対訳つき）、その文は和訳ツールで「完全一致」として訳されるようになる。

```js
JK.registerProblems([{
  id: 'my-univ-2025-1', subject: 'math', level: 'mid', unit: 'm-calc2',
  title: '3次関数の極値', source: { univ: '○○大学', year: 2025, no: '第1問', kind: '過去問' }, time: 10,
  body: String.raw`関数 $f(x) = x^{3} - 3x$ の極大値を求めよ。`,
  parts: [{ type: 'num', answer: 2 }],
  solution: [{ m: String.raw`f'(x) = 3x^{2} - 3 = 3(x+1)(x-1)`, n: 'x = -1 で極大、f(-1) = 2。' }]
}]);
```

### 成蹊大学 理工学部の過去問について

`js/data/seikei-*.js` は、2023〜2025 年度の出題分野・形式・難易度・設問の流れに合わせて作った **類題**（数値・設定・文面は自作、`source.kind: '類題'`）。
入試問題の原文は著作物のため収録していない。原文で演習したい場合は上の方法で自分用に登録する。年度別の出題傾向は `docs/seikei-analysis-*.md`。

## 開発

```bash
node tools/selftest.js                      # 共通基盤の自己テスト
node tools/validate.js --all --inventory    # 全データ・全モジュールの検証と件数
node tools/simcheck.js                      # 乱数演習の点検（通り数・答えと解説のずれ・解説に答えが出ない設問・表示の数値で計算し直すと合わない式）
node tools/exdump.js mech-incline mid 3     # 乱数演習を 1 題、文字で表示（種 3）
```

進捗と再開手順は [PROGRESS.md](PROGRESS.md)、データ形式と API は [docs/CONTRACT.md](docs/CONTRACT.md)。
